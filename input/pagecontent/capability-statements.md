
The following CapabilityStatements define the specific capabilities that different types of systems are expected to have in order to comply with this implementation guide. Systems conforming to this implementation guide are expected to declare conformance to one or more of the following capability statements.

- [AU PD Requester CapabilityStatement](CapabilityStatement-au-pd-requester.html)

This CapabilityStatement describes the basic rules for the [AU PD Requester actor](ActorDefinition-au-pd-actor-requester.html) that is responsible for creating and initiating the queries for information. The complete list of FHIR profiles, RESTful operations, and search parameters supported by AU Provider Directory Requesters are defined in this CapabilityStatement. 

- [AU PD Responder CapabilityStatement](CapabilityStatement-au-pd-responder.html)

This CapabilityStatement describes the basic rules for the [AU PD Responder actor](ActorDefinition-au-pd-actor-responder.html) that is responsible for providing responses to queries submitted by AU PD Requester actors. The complete list of FHIR profiles, RESTful operations, and search parameters supported by AU Provider Directory Responders are defined in this CapabilityStatement.
